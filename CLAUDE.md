# CS-101126-APPS: Cardsite for Apple platforms

The plan, scope and ownership are in `docs/launch/PARITY-PLAN.md`. Status and owner decisions are in `docs/launch/native-apple.md`.

## Layout
- `platform/apps/apple`: the app. It is one multiplatform SwiftUI target generated by XcodeGen from `project.yml`.
- `platform/apps/apple/Packages/CardsiteKit`: the API client and models. Each domain has its own files, `APIClient+<Domain>.swift` and `Models+<Domain>.swift`.
- `platform/studio/packages/swift`: StudioKit, the canonical design system. All colour, type, spacing and radius come from here.
- Read-only references live outside the repo, under `/home/claude/src`:
  - the web platform: `cardsite-platform_0.0.0`;
  - the web app: `apps/web/src`;
  - the API: `apps/api`;
  - the OpenAPI spec: `shared/contracts/openapi.yaml`;
  - the newer StudioKit 1.10: `studio-design-system_0.0.0/packages/swift`.

## Rules
- The contract is what the server does. Every write sends `X-Requested-With`. An empty list arrives as `data:null`. The error envelope is `{error:{title,message,code}}`. To learn a request or response shape, read the Go handlers in `apps/api`.
- Use Studio tokens only. Never put colour, spacing or font literals in `Cardsite/`. The `.meta`, `.label` and `.kicker` styles are uppercase, so never use them for sentences, emails or URLs.
- Use native chrome: `TabView`, `NavigationSplitView`, toolbars, sheets, menus and `Form`. Liquid Glass goes only on chrome. Content sits on opaque Studio surfaces.
- Every screen designs all six states: loading, empty, content, refreshing over stale data, offline, and error.
- The app sells nothing and links to no purchase. The plan is shown read-only.
- Concurrency is Swift 6 strict. Models are `@MainActor @Observable`. `APIClient` is an actor. Closures passed to `.task` are `@Sendable`.
- Availability: the deployment targets are iOS 18 and macOS 15. Gate anything newer with `#available`, and gate platform code with `#if os(...)`.
- Never claim that code compiled, that tests passed or that a screen looks right unless that was run. There is no Swift toolchain in this workspace; macOS CI is the compiler.
- Agents edit only the directories they own (PARITY-PLAN §8) and do not commit or push. The lead integrates.
